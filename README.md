# HitDeck event wheel

Mobile-friendly wheel for the free HitDeck ASCC event giveaway. Open index.html or the GitHub Pages site.

First visit starts in demo mode. Staff manually verify both Facebook and LINE follows. Each visitor gets one free gift. Staff confirm handover before the next draw.

Inventory and history are stored locally in each browser. Devices do not share inventory. Use one event device and export JSON backups from the management panel.

Product photos and character artwork are illustrative; actual gifts are supplied at the event. Third-party characters and images belong to their respective owners.
